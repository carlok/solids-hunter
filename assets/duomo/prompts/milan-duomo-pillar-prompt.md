# Milan Duomo Pillar Shaft Prompt

Create a game-ready GLB object representing the vertical shaft or trunk of an internal Milan Duomo pillar.

The object should be interpreted at human scale, where one Babylon unit is one meter and the player eye height is roughly 1.7 meters.

Geometry:
- Start from a central cylindrical structural core.
- Use a core radius around 1.35 meters.
- Use a shaft height of 24 meters.
- Divide the circumference into eight equal radial directions.
- Attach one rounded rib or colonnette on each direction.
- Each rib radius is approximately one sixth of the core radius.
- Merge the ribs visually with the central cylinder so the perimeter reads as a soft polystyle or clover-like Gothic profile.
- Avoid tapering. The shaft stays vertically constant.
- Use smoothing or beveling at junctions so the shape feels carved and continuous rather than assembled from separate pipes.
- Put the object origin at floor center.

Material:
- Use a stylized Candoglia marble look: pale warm grey, faint pink-beige tone, high roughness, no metal.
- Add subtle vertical veins or darker lines to emphasize upward thrust.

Style:
- This is not a photogrammetric or engineering reconstruction.
- It should match the existing Solidshunter visual language: readable, stylized, moderately low-poly, but more refined than a simple cylinder.
