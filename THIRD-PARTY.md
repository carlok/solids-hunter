It does **not** cover everything in this repository. The items below carry their
own terms, and anyone redistributing this project needs to honour them.

The OFL does not restrict documents or software that merely *use* the fonts, so
this imposes nothing on the rest of the project.

## Duomo floor plan — CC BY-SA 4.0

`assets/duomo/maps/Pianta_del_Duomo_di_Milano.jpg`

- Title: *Pianta del Duomo di Milano*
- Source: [Wikimedia Commons](https://commons.wikimedia.org/wiki/File:Pianta_del_Duomo_di_Milano.jpg)
- Author: Unknown author / Istituto Campana per l'Istruzione Permanente
- Licence: [CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/)
- **Modified:** yes — re-encoded from the Commons original. Not cropped or
  retouched; the image content is unchanged.

This file is reference material for the Duomo arena's pillar spacing. It is
**not** shipped in a build — `vite.config.ts` copies only the floor texture out
of `assets/duomo/`.

Including it here is a *collection*, not an adaptation, so ShareAlike does not
reach the rest of the repository.

### `assets/duomo/maps/milan-duomo-plan-rhythm.json`

This file records bay spacings measured from the plan above, and declares that
lineage in its own `source` block. Bare factual measurements are generally not
copyrightable, so the stronger reading is that it is not an adaptation. It is
marked **CC BY-SA 4.0** here anyway, because the cost of doing so is zero and
the cost of being wrong is not. `babylon/build-duomo.ts` consumes it.

## Duomo floor texture — AI-generated

`assets/duomo/mosaico_marmoreo_rinascimentale_ornamentale.jpg`

A decorative marble-mosaic texture generated from a written prompt, chosen as an
atmospheric fit. It is **not** a reproduction of the real Duomo floor.

The prompt is recorded in `assets/duomo/prompts/`. **The generating tool is not
recorded, and should be.** Image models differ materially in what they grant
over their output, so this is an open gap rather than a settled position.

## Environment lighting — CC BY 4.0

`assets/textures/environmentSpecular.env`

- Source: [BabylonJS/Assets](https://github.com/BabylonJS/Assets), served as
  `https://assets.babylonjs.com/core/environments/environmentSpecular.env`
- Licence: [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/)
- **Modified:** no — byte-for-byte identical to the upstream file
  (MD5 `21b51fbf433e33c002a3daa5d1014511`, 273,974 bytes), verified by download
  and comparison.

The prefiltered IBL map that drives PBR reflections in every arena, and the only
third-party binary shipped to players. It was originally committed with no
recorded source; the origin was established afterwards by matching the file
against Babylon's published asset.

Note this is **CC BY 4.0**, not the Apache-2.0 that covers `@babylonjs/core` —
the assets repository carries a different licence from the engine. Attribution
is therefore required wherever the game is distributed, and is given in the
in-game credits.

## Sound effects — MIT, part of this project

Every WAV in `assets/sounds/` is generated by `tools/generate_sounds.py`, which
writes them from scratch with no third-party dependencies. No external audio is
used. The ambient bed is synthesised at runtime in `babylon/game-audio.ts`.

## Runtime dependency

[Babylon.js](https://www.babylonjs.com/) (`@babylonjs/core`) — Apache-2.0. A
build embeds it in the output bundle.
